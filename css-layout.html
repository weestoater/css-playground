CSS layout learning guide

CSS layout is not a choice between mutually exclusive systems. A page can use normal flow for its text, grid for its main regions, flexbox inside a navigation bar, and positioning for a small overlay.

Start with the [comparison and learning path](./layout-comparison.md), then explore the individual guides:

  1. Normal flow: block and inline
  2. Flexbox
  3. Grid
  4. Multi-column layout
  5. Floats
  6. Positioning
  7. Table layout
  8. Inline-block

Each guide has a small experiment, questions to investigate, and a place to record what you learn. The snippets are starting points, not prescriptions: try them in separate pages so their styles do not interfere with each other.

When testing any method, resize the browser, add longer text, zoom in, and use the keyboard. Check that the reading and tab order still make sense, and that content is not hidden or overlapping.

For an overview of the underlying concepts, see MDN: Introduction to CSS layout.
